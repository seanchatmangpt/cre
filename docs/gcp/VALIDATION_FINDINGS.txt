ISSUE #5: Build Digest Capture is Racy
────────────────────────────────────────────────────────────────────────────────
File:           .github/workflows/gcp-cloud-build.yml
Line:           85-96
Status:         CRITICAL - UNRELIABLE BUILD TRACKING

Problem Code:
  echo "digest=${IMAGE_NAME}@$(gcloud builds list --limit=1 \
    --format='value(imageSummary.digest)' --region=${{ env.REGION }})" >> $GITHUB_OUTPUT

Race Conditions:
  1. gcloud builds submit doesn't immediately return digest
  2. --format='value(imageSummary.digest)' may be empty initially
  3. gcloud builds list --limit=1 might return different build
     (if multiple builds are queued or running)
  4. No validation that build succeeded
  5. No wait logic for build completion

Consequences:
  - Security scan may run on wrong image
  - Deployment may use wrong image digest
  - Cannot reliably track which commit was deployed
  - Difficult to correlate with production issues
  - Rollback failures due to wrong image reference

Impact:
  - Unreliable deployments
  - Incorrect security scans
  - Wrong images in production
  - Difficult incident response

Fix Time:       1 hour
Difficulty:     MEDIUM

ISSUE #6: Trivy Should Fail on Vulnerabilities
────────────────────────────────────────────────────────────────────────────────
File:           .github/workflows/gcp-cloud-build.yml (security-scan job)
Status:         HIGH - SECURITY RISK

Current Code:
  trivy image \
    --severity CRITICAL,HIGH \
    --format json \
    --output trivy-results.json \
    "${IMAGE_DIGEST}"

Problem:
  - Pipeline continues even if CRITICAL vulnerabilities found
  - Vulnerable images can reach production
  - Security scan is informational only

Fix:
  trivy image \
    --exit-code 1 \
    --severity CRITICAL,HIGH \
    --format json \
    --output trivy-results.json \
    "${IMAGE_DIGEST}"

Impact:
  - Vulnerable images deployed to production
  - Compliance violations
  - Security incidents possible

Fix Time:       5 minutes
Difficulty:     TRIVIAL
Risk if Not Fixed: HIGH
