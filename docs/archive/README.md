## Why Archive Instead of Delete?

1. **Historical Reference** - Preserved for understanding evolution of the project
2. **Possible Recovery** - Content may be needed for future reference
3. **Link Preservation** - Old links may still reference these files
4. **Audit Trail** - Shows what changed and when

## Updating Links After Archival

If you find broken links pointing to archived files:

1. Check the corresponding **Replacement** section above
2. Update the link to point to the current documentation
3. Or restore content if still needed
