## 1. Basic Control Flow Patterns (WCP-1 to WCP-5)

### WCP-1: Sequence
**Description**: A task in a workflow is enabled after the completion of a preceding task.

**Use Case**: Sequential task execution where Task B starts after Task A completes.

### WCP-2: Parallel Split (AND-split)
**Description**: Divergence of a single branch into multiple parallel branches.

**Use Case**: Creating concurrent execution paths from a single point.

### WCP-3: Synchronization (AND-join)
**Description**: Convergence of multiple parallel branches into a single thread.

**Use Case**: Waiting for all parallel branches to complete before proceeding.

### WCP-4: Exclusive Choice (XOR-split)
**Description**: Choice between alternative branches based on a condition.

**Use Case**: Conditional branching where exactly one path is taken.

### WCP-5: Simple Merge (XOR-join)
**Description**: Convergence of alternative branches without synchronization.

**Use Case**: Merging alternative paths that were created by XOR-split.
