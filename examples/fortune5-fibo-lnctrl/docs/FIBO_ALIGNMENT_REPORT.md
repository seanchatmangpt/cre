## FIBO Namespaces

The following FIBO namespaces are recognized:

- `fibo-fnd`: Foundations (Party, Agreement, Account, etc.)
- `fibo-be`: Business Entities (LegalEntity, Corporation, etc.)
- `fibo-loan`: Loans (Loan, Borrower, LoanContract, etc.)
- `fibo-fbc`: Financial Business & Commerce (Bank, Lender, etc.)
- `fibo-sec`: Securities
- `fibo-der`: Derivatives
- `fibo-ind`: Indices & Indicators

## Recommendations

1. Update custom terms to use FIBO vocabulary
2. Create `ontology/fibo_alignment.ttl` with explicit mappings
3. Import FIBO ontologies in your main ontology file
4. Use `owl:equivalentClass` for custom term mappings
